# ILU QUEST — интерактивный прототип

Четырёхстраничный сайт-гид по местам Элисты. В проекте есть главная страница, каталог с фильтрами, динамическая страница отдельного места и личный кабинет. Избранное, посещения, пользовательские отзывы и коллекции сохраняются в `localStorage` браузера.

## Как запустить

Самый простой способ — открыть папку через локальный веб-сервер.

**Python** (если установлен):

```bash
cd place-quest-site
python -m http.server 8000
```

После этого откройте в браузере: <http://localhost:8000>

Также можно открыть `index.html` напрямую, но локальный сервер надёжнее для загрузки внешних ресурсов и карт.

## Подключение Яндекс Карт

1. Получите ключ JavaScript API в [Кабинете разработчика Яндекса](https://developer.tech.yandex.ru/).
2. Откройте `config.js`.
3. Вставьте ключ вместо пустой строки:

```js
window.PLACE_QUEST_CONFIG = {
  yandexMapsApiKey: 'ВАШ_КЛЮЧ'
};
```

4. В кабинете Яндекса ограничьте ключ разрешёнными доменами проекта.
5. Перезапустите страницу сайта.

После подключения сайт создаст интерактивную карту, геокодирует адреса заведений и добавит метки. Если ключ не указан или API недоступен, остаётся запасной блок с переходами на поиск каждого места в Яндекс Картах.

**Важно:** адреса заведений взяты из исходного списка. Координаты пока не зафиксированы вручную: сайт запрашивает их у геокодера Яндекса при первой загрузке карты. Проверьте положение всех меток перед публичной публикацией. Если геокодер выберет не тот дом или улицу, укажите подтверждённые `lat` и `lon` в `data.js` для нужного места — тогда геокодирование для него не потребуется.

## Что уже работает

- навигация между главной, каталогом, страницей конкретного заведения и личным кабинетом;
- 12 мест из исходного списка;
- фильтр по категориям, тегам, цене и строке поиска;
- сортировка по рейтингу, цене и названию;
- список и карта в каталоге;
- динамическая страница каждого места по его ID;
- отметка избранного и посещённых мест;
- создание коллекций и добавление туда мест;
- пользовательские отзывы и пересчёт отображаемого рейтинга с учётом новых отзывов;
- базовые достижения;
- адаптивная вёрстка для мобильных экранов.

## Ограничения демоверсии

- `localStorage` привязан к браузеру и устройству. Данные не синхронизируются между разными людьми или устройствами.
- Отзывы сохраняются только в браузере текущего пользователя. Для общедоступных отзывов, регистрации и общего кабинета понадобится сервер и база данных.
- Профиль демонстрационный, без настоящей авторизации.
- Фотографии заведений загружаются с Unsplash по сети. При отсутствии интернета показывается локальная иллюстрация-заглушка.
- Данные о местах введены по предоставленному списку и не проверялись как актуальная информация о реальных организациях.

## Структура проекта

```text
place-quest-site/
├── index.html           # каркас приложения и общая навигация
├── styles.css           # дизайн и адаптивная вёрстка
├── app.js               # маршрутизация, фильтры, LocalStorage, карты
├── data.js              # 12 мест и демонстрационные отзывы
├── config.js            # ключ Яндекс Карт (заполнить самостоятельно)
├── config.example.js    # пример конфигурации
└── assets/
    ├── ilu-quest-logo.png # логотип из нового фирменного знака
    ├── hero-art.webp      # фрагмент предоставленного хиро-макета
    └── photo-placeholder.svg
```
